# Cocos MCP Pro 与本地首版对比

> 本文保留本地 0.1.0 的历史对比。当前 0.2.0 与 Pro 的详细分析、公开版源码清单和超越目标见 [最新分析与规格](PRO-CAPABILITY-ANALYSIS.md)。该新报告补充了 README 关于 builder/composite 快照失败回滚的声明；本文当时的未知项不能作为当前完整结论。

核对日期：2026-10-28。对方：官网当前展示的 **Cocos MCP 3.x Pro v1.8.1**；本地：**CocosCreatorMCP 0.1.0**，Creator 3.8.8 + Codex。

## 证据范围

Pro 信息来自[官方产品页](https://www.vberai.com/game-engines/cocos)的功能说明、更新日志、定价和 FAQ。点击下载会要求登录，当前未取得 Pro 安装包、运行时工具清单或源码，也未运行 Pro。因此，下表的 Pro 能力均为官方声明，不是本机验收结论。

本地能力来自现有源码、[覆盖记录](COVERAGE.md)、`artifacts/live-check.json` 和 `artifacts/ui-check.json`。本地记录包含 5 项自动测试、15 项真实 Creator 检查及窗口操作验证；这些测试仍不代表完整游戏开发流程已经验收。

此前对 GitHub 公开版 1.5.4 的源码发现，仅适用于所审提交，不能外推到 Pro。官网现标为 1.8.1，早先 README 的 1.7.8 不是本次版本依据。

## 对“完全接管编辑器”的判断

按公开功能范围，Pro 在预制体、UI 模板、动画/Spine、知识库和校验方面明显比本地首版更完整。不能把本地通用执行接口可能完成的任务，视为已经提供并验收的专用功能。

本地首版已证明在当前 Creator 3.8.8 + Codex 环境中，基础编辑和部分真实界面操作可用。它便于定制，但目前仍是基础控制层，不应宣称功能整体超过 Pro。

双方现有证据都不能证明“人能做的所有操作都能完美自动完成”。截图代表可以观察画面，不能单独证明鼠标操作、弹窗处理、动画编辑、预制体引用、预览交互和构建全部稳定。

## 当前能看见和不能确认的内容

能直接核对：功能类别、版本、兼容范围、协议声明、FAQ、授权说明、公开更新日志。官网还提供需登录领取的 3 天全功能体验。

尚不能确认：231 项操作的完整参数定义、实际成功率、Codex 兼容表现、Token 节省幅度、截图范围与速度、复杂编辑器面板输入、自动构建闭环，以及回滚/超时/权限实现。

Pro 的商业授权与公开源码许可应分别判断。Pro 的动态截图能力已经公开声明，因此之前公开版对比中的“本地有截图/输入”不能整体作为对 Pro 的独有优势。官网更新日志还声明修复了多项目端口问题，不能直接沿用公开版固定端口方面的结论。

## 进一步实测的对照任务

若后续取得合法可运行的 Pro 体验版，应在两个独立测试项目里完成相同任务，并比较耗时、调用次数、最终结果和失败恢复，而不是只比较工具数量：

1. 从空场景生成带布局、按钮事件和脚本引用的登录界面，保存并重开检查。
2. 创建包含自定义脚本和贴图的预制体，实例化、覆盖属性、应用和还原，检查引用及撤销。
3. 制作带关键帧和事件的动画并预览；有合法测试资源时再检查 Spine。
4. 故意设置错误引用或不合理布局，检查诊断、修复及截图是否与实际画面一致。
5. 启动预览、获取运行错误并修复，构建目标平台并验证产物确实生成。
6. 多项目同时连接、断连重连、长操作超时和失败后继续编辑。

这一阶段需要安装包和可用体验/授权，但当前公开功能比较已经可以完成，无需为此购买产品或提供账号密码。
